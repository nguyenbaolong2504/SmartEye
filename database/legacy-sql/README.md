# Tài liệu SQL của phiên bản cũ

Các file trong thư mục này được giữ để tham khảo dữ liệu/schema trước khi chuyển MongoDB. Backend hiện tại không sử dụng SQLAlchemy, SQLite hoặc PostgreSQL. Không import các file này theo hướng dẫn chạy MongoDB hiện tại. Các test cũ ở đây chỉ là lịch sử, không thuộc bộ kiểm thử đang chạy.

Dữ liệu SQL cũ không tự chuyển sang MongoDB. Backend/data chứa DB cá nhân trước đó được giữ nguyên; không dùng nó làm nguồn seed MongoDB.
